# GigaVibeMiptCode

Консольный чат-бот для общения с языковыми моделями через OpenAI.

Поддерживает локальные сервисы (Ollama) и облачные сервисы (OpenRouter, GigaChat и др.).

## Требования

- Python 3.10 или выше
- Установленные зависимости из `requirements.txt`
- Работающий сервер LLM (например, Ollama) или доступ к облачному API

## Установка и запуск

Склонируйте репозиторий и перейдите в папку проекта: `final_project`

Запустите `main.py` и пользуйтесь ботом, вот некоторые команды:

- \q выход
- /reset сброс истории и экрана
- @::Путь:: вставить текстовый файл до 5мб
- /file_chunk обработка файла по частям
